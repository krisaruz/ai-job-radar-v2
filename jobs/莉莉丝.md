## 测试开发(AI方向)（1）

### 平台测试开发工程师

📍 上海 | 🏢 测试

🔗 [投递链接](https://lilithgames.jobs.feishu.cn/career/position/7688674315667261715/detail)

**岗位职责：**

1. 平台质量保障：负责公司内部平台的质量保障，包括 DevOps 平台、舆情系统、客服系统和游戏研发/运营工具。工作覆盖 Web 前端、服务端接口和数据链路，要求能独立完成测试方案设计、测试执行和上线验收。

2. 测试工具与自动化建设：设计、开发并维护接口自动化、UI 自动化和数据校验等测试框架与工具，接入 CI/CD 流水线，持续提高回归效率和测试覆盖率。

3. AI Native 研发测试工作流：探索大模型和 Agent 在研发测试中的落地，并把可行的做法推广到团队。方向包括 AI 生成测试用例和测试数据、AI 辅助缺陷分析与定位、智能回归、基于 Agent 的自动化测试执行，以及 MCP/Skill 等工具的建设。

4. AI 功能质量评估：对舆情、客服等平台里的大模型能力（如智能分类、智能回复、摘要）建立评测集、评估指标和回归机制，保证 AI 功能的效果稳定、可以量化。

5. 团队管理：带领4名外包测试工程师，负责任务拆解和排期、测试用例评审、执行质量把控和能力培养，保证交付质量和进度。

6. 质量体系与流程：参与需求评审和技术方案评审，推动可测性改进。建设缺陷度量、质量看板等数据化手段，持续优化研发测试流程。

**岗位要求：**

1. 本科及以上学历，3 年以上测试开发经验，有 Web 平台或后台系统的测试经验，能独立负责一个或多个项目的全流程质量工作。

2. 熟练掌握至少一门编程语言（Python / Go / Java），有扎实的编码能力，能独立开发测试框架、平台或提效工具。

3. 熟悉接口测试和自动化测试体系，熟练使用 Pytest、Playwright/Selenium、Postman、JMeter 等工具，熟悉 Jenkins/GitLab CI 等 CI/CD 流程。

4. 了解 MySQL、Redis、Kafka 等常用数据库和中间件，具备通过日志、链路和数据定位问题的能力。

5. 对 AI 辅助研发有浓厚兴趣并有实际使用经验，熟练使用 Claude Code、Cursor 等 AI 编程工具，了解 Prompt 工程、Agent 和 MCP 等概念。

6. 熟悉测试理论和测试设计方法，有良好的风险识别能力和质量意识。

7. 有带团队或管理外包的经验，具备良好的沟通协调、任务拆解和推动落地能力。

8. 自驱力强，乐于尝试新技术，并能把个人实践沉淀成团队可复用的方法和工具。
