## 大模型/AI测试（1）

### 资深测试工程师（发行方向）

📍 上海 | 🏢 测试

🔗 [投递链接](https://lilithgames.jobs.feishu.cn/career/position/7606016773801019694/detail)

**岗位职责：**

1. 负责发行及代理项目整体质量保障，制定测试策略、测试计划与测试用例，覆盖功能、兼容性、性能、合规性等全维度测试，确保项目全流程的顺利落地。

2. 负责项目的跨团队协作沟通，对接研发、运营、发行等多部门，同步测试进度、反馈核心问题、推动缺陷闭环；针对代理项目的版本迭代、本地化适配等需求，输出清晰的质量评估报告。

3. 主导流程中的质量风险把控，识别项目在版本交付、合规审核，商店上架等环节的质量风险，制定应对方案并推动执行。

4. 主导测试效率提升，推动测试工具的引入和落地。搭建 / 优化自动化测试脚本，提升回归测试效率；参与测试工具的选型与二次开发，解决项目中的复杂测试问题。

**岗位要求：**

1. 本科以上学历，计算机，通信或相关专业。

2. 具备3年以上游戏自研 / 代理项目测试经验，熟悉移动端游戏从引入评估、本地化测试到上线验收的全流程质量管控要点。

3. 具备全链路质量思维，能够独立规划并推进测试工作；沟通协调能力强，能高效对接内外部团队；抗压能力突出，可适应项目冲刺期的高强度工作节奏。

4. 拥有一定测试开发能力和工具开发经验，能够完成业务过程中的的优化评估，通过引入自动化或大模型工具帮助团队提效。

5. 熟悉游戏测试的核心流程与方法，了解主流手游 / 端游的兼容性、性能测试要点；具备良好的文档编写能力，能输出规范的测试报告与缺陷分析报告。

## 测试开发(AI方向)（1）

### 平台测试开发工程师

📍 上海 | 🏢 测试

🔗 [投递链接](https://lilithgames.jobs.feishu.cn/career/position/7688674315667261715/detail)

**岗位职责：**

1. 平台质量保障：负责公司内部平台的质量保障，包括 DevOps 平台、舆情系统、客服系统和游戏研发/运营工具。工作覆盖 Web 前端、服务端接口和数据链路，要求能独立完成测试方案设计、测试执行和上线验收。

2. 测试工具与自动化建设：设计、开发并维护接口自动化、UI 自动化和数据校验等测试框架与工具，接入 CI/CD 流水线，持续提高回归效率和测试覆盖率。

3. AI Native 研发测试工作流：探索大模型和 Agent 在研发测试中的落地，并把可行的做法推广到团队。方向包括 AI 生成测试用例和测试数据、AI 辅助缺陷分析与定位、智能回归、基于 Agent 的自动化测试执行，以及 MCP/Skill 等工具的建设。

4. AI 功能质量评估：对舆情、客服等平台里的大模型能力（如智能分类、智能回复、摘要）建立评测集、评估指标和回归机制，保证 AI 功能的效果稳定、可以量化。

5. 团队管理：带领4名外包测试工程师，负责任务拆解和排期、测试用例评审、执行质量把控和能力培养，保证交付质量和进度。

6. 质量体系与流程：参与需求评审和技术方案评审，推动可测性改进。建设缺陷度量、质量看板等数据化手段，持续优化研发测试流程。

**岗位要求：**

1. 本科及以上学历，3 年以上测试开发经验，有 Web 平台或后台系统的测试经验，能独立负责一个或多个项目的全流程质量工作。

2. 熟练掌握至少一门编程语言（Python / Go / Java），有扎实的编码能力，能独立开发测试框架、平台或提效工具。

3. 熟悉接口测试和自动化测试体系，熟练使用 Pytest、Playwright/Selenium、Postman、JMeter 等工具，熟悉 Jenkins/GitLab CI 等 CI/CD 流程。

4. 了解 MySQL、Redis、Kafka 等常用数据库和中间件，具备通过日志、链路和数据定位问题的能力。

5. 对 AI 辅助研发有浓厚兴趣并有实际使用经验，熟练使用 Claude Code、Cursor 等 AI 编程工具，了解 Prompt 工程、Agent 和 MCP 等概念。

6. 熟悉测试理论和测试设计方法，有良好的风险识别能力和质量意识。

7. 有带团队或管理外包的经验，具备良好的沟通协调、任务拆解和推动落地能力。

8. 自驱力强，乐于尝试新技术，并能把个人实践沉淀成团队可复用的方法和工具。

## AI/Agent产品（1）

### 产品经理（活动中台与 AI Agent 工作流）

📍 上海 | 🏢 互联网 / 电子 / 网游

🔗 [投递链接](https://lilithgames.jobs.feishu.cn/career/position/7667872138321266990/detail)

**岗位职责：**

1. 负责网页活动产品工作，服务游戏促活、付费、裂变等业务场景；完成方案设计、需求输出和排期推进，参与开发联调、测试验收及上线验证，推动从需求沟通到交付上线的全流程闭环。

2. 主导活动业务的 AI Agent 化，负责 Agent 的任务拆解、上下文与状态管理、工具定义与调度、流程分支、异常恢复及人机协同机制设计，推动方案开发落地。

3. 建立 Agent 效果评测和持续迭代机制，通过测试集、过程指标、失败分类和线上结果验证 Agent 的可用性与稳定性。

4. 负责串联内部上下游团队及外部供应商，推进需求澄清、方案设计、进度管理和交付验收，保障项目按期、高质量落地。

5. 参与中台其他业务的 AI Agent 设计与维护，沉淀可复用的工具、工作流和 Agent 能力，探索新的业务协作模式。

**岗位要求：**

1. 1 年及以上产品或 AI Agent 相关工作经验；至少深度参与过一个 Agent 项目的核心设计、落地或效果验证。有游戏、活动或中台经验者优先。

2. 具备实际的 Agent 设计能力，能够完成场景拆解、任务流程设计、上下文与状态管理、工具调用编排、异常处理及效果评测，并能清晰说明本人承担的设计与决策。

3. 能够判断不同环节应采用模型、规则、代码还是人工处理，并对准确性、稳定性、成本和效率进行取舍；不局限于 Prompt、知识库或业务规则配置。

4. 具备技术动手能力，能够完成接口接入、脚本或 CLI 封装、联调及排障，并与研发共同完成交付；能够借助 AI 工具独立完成开发、部署和验证闭环者优先。

5. 具备较强的业务理解、系统抽象、项目管理及跨团队协作能力，能够将复杂场景转化为可复用、可配置的产品方案。
