## 测试开发(AI方向)（1）

### Agent 测试开发工程师

📍 北京

🔗 [投递链接](https://modelbest.jobs.feishu.cn/career/position/7708693067117496617/detail)

**岗位职责：**

1. 负责大模型智能体（Agent）平台、智能体编排、工具调用网关、RAG、多智能体协同系统的质量基建与自动化评测体系建设，以评测平台、自动化能力交付为主。

2. 设计、开发、维护 Agent 自动化评测框架，基于 Python 开发评测套件，实现批量评测、自动判分、版本对比、A/B 实验效果分析。

3. 构建标准化评测数据集、黄金用例、负面对抗样本库，围绕任务完成率、工具调用准确率、幻觉、引用溯源、上下文一致性、拒绝对齐、意图识别等指标，开发可复用评估集。

4. 搭建 CI/CD 评测流水线，将 Agent 效果回归、接口自动化、性能压测、安全检测嵌入发布流程，实现版本准入自动校验、效果退化告警、badcase 自动采集与聚类。

5. 负责智能体链路专项测试开发：Function Calling / MCP 协议测试、长上下文稳定性、并发调度压测、故障注入、Prompt 注入越狱对抗、隐私越权风险检测工具开发。

6. 定位并区分问题边界：模型底座、Prompt 模板、检索链路、工具服务、Agent 调度引擎；沉淀质量规范、评测基线，赋能业务自助评测，持续优化评测信度与成本。

7. 参与需求评审、架构评审，质量左移，推动算法、后端、产品对齐验收标准与指标。

**岗位要求：**

1.  本科及以上学历，3 年及以上测试开发经验，有 LLM Agent、RAG、对话系统评测落地经验优先。

2. 熟练 Python，熟悉HTTP/OpenAI 接口协议；能独立开发评测脚本、评估算子、简单评测看板；了解 Git、CI/CD（Github Actions / Jenkins）。

3. 理解智能体核心链路：规划、记忆、工具调用、反思、多 Agent 协作；熟悉 LangChain / LlamaIndex / MCP 优先。

4. 掌握 LLM 评测方法论：LLM-as-judge、人工评估、指标量化、样本抽样、置信度与统计显著性；理解幻觉、随机性、评估主观性带来的工程难点。

5. 具备接口自动化、性能压测、故障注入开发经验；了解向量库、推理服务（vLLM 等）、检索链路优先。

6. 有 AI 安全测试经验：Prompt 注入、越狱、数据泄露、越权调用工具等对抗场景优先。

7. 熟练使用主流vibe coding工具。

## AI/Agent产品（1）

### Agent 客户交付产品经理

📍 北京

🔗 [投递链接](https://modelbest.jobs.feishu.cn/career/position/7706460423302252851/detail)

**岗位职责：**

1.负责律所和法律客户的需求调研、场景分析和产品方案设计，明确项目范围、交付目标及验收标准；

2.将律师工作流程转化为清晰的产品需求，完成需求文档、业务流程、原型和版本规划；

3.协调设计、研发、测试及客户团队，推动产品配置、系统接入、试用培训和项目交付；

4.跟踪客户真实使用情况，组织试用复盘和用户访谈，分析产品问题并推动版本迭代；

5.识别不同客户需求中的共性，沉淀标准功能、配置方案、交付流程和验收规范；

6.参与法律AI核心场景及创新能力的规划，持续提升产品可用性、使用深度和客户价值。

**岗位要求：**

1.本科及以上学历，3年以上B端产品、解决方案或企业软件交付经验；

2.能够独立完成需求调研、业务分析、产品方案、项目推进和交付复盘；

3.具备较强的业务理解和抽象能力，能够区分标准产品需求、可配置需求与客户定制需求；

4.熟悉企业软件的账号权限、数据接入、API集成、私有化部署等常见交付场景；

5.具备良好的沟通、文档和项目管理能力，能够协调客户与内部团队推动问题解决；

6.对AI产品有基本理解，能够关注结果准确性、来源可信度、异常处理和用户反馈。

加分项

1.有法律科技、律所服务或专业服务行业经验；

2.有AI Agent、大模型应用、知识库或智能检索产品经验；

3.有律所、金融机构或大型企业客户交付经验；

4.具备法律专业背景，或熟悉合同审查、法律检索、案卷整理等律师工作场景；

5.有从客户项目中提炼标准产品能力的成功经验。
