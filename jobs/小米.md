6、具备较强的逻辑思维能力、问题分析与解决能力，能够快速定位并解决测试过程中出现的复杂问题，对测试结果进行深入分析与总结，提出有效的改进措施与建议。

7、具有良好的沟通协作能力与团队合作精神，能够与不同背景的团队成员进行有效的沟通与协作，共同推动项目的进展与产品质量的提升。

8、具备较强的学习能力与自我驱动力，能够主动关注 AIGC 领域的新技术、新方法与新趋势，不断学习与掌握新的测试技术与工具，提升自身的专业素养与能力水平。

### （活水）操作系统测试工程师

📍 南京 | 🏢 手机部

🔗 [投递链接](https://xiaomi.jobs.f.mioffice.cn/index/position/7649587091789318450/detail)

**岗位职责：**

1、负责窗口、渲染、显示框架的黑屏、花屏、闪屏问题深度分析与复盘，攻坚显示类疑难异常，保障整机显示体验稳定。

2、以蓝军竞品对标思路，搭建显示异常专项分析模型；排查系统服务锁竞争、内存、IO、调度等核心资源问题，定位产品与竞品本质差异，沉淀可复用的分析方法论与工具链，支撑常态化体验优化。

3、搭建三层内存 Benchmark 评测体系

搭建覆盖应用进程、系统服务、设备老化的三层内存评测体系，聚焦杀后台、卡顿、冷启异常、掉帧等用户长体验问题；对标竞品 kswapd、LMK 内存管理机制，量化性能差异，推动内存体验优化落地。

4、构建 SOC Benchmark，支撑芯片硅前、硅后选型评估

基于核心用户场景，从 CPU、GPU、DDR、NPU、ISP、功耗多维度搭建可复跑、可横评、可量化的 SOC 评测体系；在项目早期完成性能评估与风险预判，输出选型建议，支撑芯片与平台决策。

5、搭建端侧 AI 性能与体验 Benchmark 体系

面向 LLM、VLM、ASR、TTS、端侧 Agent 搭建 AI 评测体系，覆盖响应时延、吞吐、能耗、内存、热稳定性等核心指标，兼顾AI任务与前台体验的耦合影响，为模型选型、量化方案、Runtime适配及资源调度优化提供数据支撑。

6、探索 AI 与系统协同差异化能力

围绕智能调度、智能内存、智能续航等方向，探索AI与系统服务深度协同能力；通过竞品对比挖掘差异化机会点，落地创新功能，构筑产品长期技术壁垒。

**岗位要求：**

1、计算机、电子、通信、自动化等相关专业本科及以上学历

2、深入理解 Android 系统架构，熟悉 Framework（WMS / SurfaceFlinger / Choreographer 等）、渲染与显示链路，具备黑花闪类问题的独立分析定位能力。

3、熟悉 Linux 内存管理机制（kswapd、LMK / LMKD、PSI、ZRAM 等），能够独立完成内存行为分析与竞品对标。

4、熟悉 SoC 体系结构，了解 CPU / GPU / DDR / NPU / ISP 的工作机制及性能/功耗评估方法，具备 benchmark 设计与横向评测经验。

5、熟练使用 systrace / perfetto / simpleperf / ftrace 等性能分析工具，具备脚本化与自动化能力（Python / Shell 等）。
