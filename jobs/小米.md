### AI测试工程师

📍 北京 | 🏢 手机部

🔗 [投递链接](https://xiaomi.jobs.f.mioffice.cn/index/position/7688937643912497449/detail)

**岗位职责：**

1、负责AI算法的质量保障工作，负责算法效果的测试框架和测试标准的搭建；

2、分析业务产品需求、技术方案，负责测试方案的设计，制定合理高效的测试方案；

3、AI测试体系建设，构建AI原子能力、大语言模型、多模态感知、AIGC等算法的评测模型；

4、与产品经理、开发工程师、算法工程师等密切协作，参与产品的需求评审、设计评审与代码审查等环节，提前介入产品开发过程，提供测试视角的意见与建议，促进产品质量的前置保障。

5、编写详细、准确的测试报告，向项目团队、管理层及相关利益者汇报测试进展、发现的问题、质量状况及改进建议，确保各方对产品质量有清晰、全面的了解与认识

**岗位要求：**

1、本科及以上学历，计算机、数学、统计学、模式识别、图像处理等相关方向；

2、熟练掌握至少一种编程语言（如 Python、Java 等），具备良好的代码编写与调试能力，能够独立开发自动化测试脚本与工具。

3、对当前AIGC大模型算法评估有成体系的方法论，主客观评价方法都较为精通，对主流AIGC大模型算法的评价指标较为了解

4、有AI图像、自然语言（NLU,NLG）、多模态等一种或多种算法的评估测试经验，有大模型方面测试经验优先；

5、关注CVPR，NeurIPS， AAAI等AI相关顶会的最新动态，对其中优秀论文能动手复现

6、具备较强的逻辑思维能力、问题分析与解决能力，能够快速定位并解决测试过程中出现的复杂问题，对测试结果进行深入分析与总结，提出有效的改进措施与建议。

7、具有良好的沟通协作能力与团队合作精神，能够与不同背景的团队成员进行有效的沟通与协作，共同推动项目的进展与产品质量的提升。

8、具备较强的学习能力与自我驱动力，能够主动关注 AIGC 领域的新技术、新方法与新趋势，不断学习与掌握新的测试技术与工具，提升自身的专业素养与能力水平。

### 小米汽车-智能制造-灵巧手测试工程师

📍 北京 | 🏢 汽车部

🔗 [投递链接](https://xiaomi.jobs.f.mioffice.cn/index/position/7675309469694478643/detail)

**岗位职责：**

1. 灵巧手测试规划与方案

- 参与灵巧手需求评审：驱动、减速器、编码器、力矩传感器、触觉传感器、腱驱 / 直驱、手指机构等；

- 制定测试策略与计划，编写测试用例 / 规程 / 验收标准，覆盖功能、性能、寿命、安全、环境、抓取场景。

2. 灵巧手核心指标测试执行

- 手指 / 关节：角度范围、速度、加速度、定位精度、重复定位精度、回差、空载 / 带载特性；

- 力控与感知：指尖力矩 / 力、关节力矩、力控带宽、柔顺控制、碰撞检测、触觉传感器响应与一致性；

- 抓取与操作：夹持力、夹持范围、稳定抓取、精细操作、自适应抓取、负重保持、防打滑、防夹伤；

- 可靠性与耐久：手指开合循环耐久、抓取耐久、传感器耐久、高低温、湿热、振动、跌落、防护等级。

3. 测试环境搭建与工具开发

- 搭建灵巧手测试台架和调试：力控传感器、位移 / 角度采集、高速摄像、负载工装、尺寸、功能验证等；

- 具备一定传感器标定、数据采集与自动化测试程序及软件开发能力，提升测试效率与复现度；

- 编写测试软件及程序，确保研发需求的测试项均能覆盖。

4. 缺陷定位与质量闭环

- 复现抓取失败、卡顿、抖动、力控不准、发热异常、断触、断驱等问题；

- 输出测试报告、失效分析、改进建议，推动机械 / 电控 / 算法 / 结构优化。

5. 标准与文档

- 维护测试用例库、数据基线、可靠性库；

- 配合产品安全与合规，输出测试证据与验证记录。

**岗位要求：**

1. 岗位要求：

- 本科及以上，自动化、机器人工程、机电一体化、测控技术、机械电子、电气工程等相关专业。

- 1 年以上灵巧手 / 多指手 / 末端执行器 / 伺服驱动 / 力控传感器测试经验优先；

- 机器人、外骨骼、协作机器人、医疗执行器相关经验优先。

- 理解灵巧手基本原理：手指机构、驱动、减速器、编码器、力矩 / 触觉传感器、力控 / 柔顺控制；

- 能使用示波器、电源、万用表、力矩传感器、数据采集仪等设备；

- 能独立编写测试用例、输出测试报告，使用缺陷管理工具（Jira等）

2. 加分项

- 有抓取测试、力控标定、耐久测试、触觉传感器测试经验；

- 会 Python / LabVIEW / C#，能做自动化测试与数据解析；

- 熟悉 ROS、运动控制、电机驱动、传感器信号处理；

- 了解机器人安全、安规、EMC、可靠性统计与 DOE。
